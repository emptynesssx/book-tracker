# 📚 Book Tracker — Трекер прочитанных книг

**Автор:** Салихова Арина
**Дата создания:** 04.05.2026

## 📖 О проекте

Book Tracker — это графическое приложение для учёта прочитанных книг. 
Программа позволяет добавлять книги, фильтровать их по жанру и количеству страниц, 
а также сохранять данные в JSON-файл.

### Возможности:
- ✅ Добавление книг с указанием названия, автора, жанра и количества страниц
- ✅ Валидация ввода (проверка на пустые поля и корректность числа страниц)
- ✅ Фильтрация по жанру (частичное совпадение)
- ✅ Фильтрация по количеству страниц (больше указанного числа)
- ✅ Сохранение и загрузка данных в формате JSON
- ✅ Удобный табличный интерфейс
- ✅ Автоматическое обновление количества найденных книг

## 🚀 Запуск программы

### Требования:
- Python 3.6 или выше

1. Скачайте все файлы проекта в одну папку
2. Откройте терминал/командную строку в этой папке
3. Запустите программу:
   ```bash
   python main.py
